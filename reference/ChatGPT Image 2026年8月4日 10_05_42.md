# 『OURS｜两个人的时光档案馆』系统开发指令

**目标：** 实现一个自动记录、整理、生成回忆日记并能智能排版的情侣回忆系统。用户（你）可以上传照片，系统自动生成日记与精美排版；你的女朋友通过密码/特殊日期进入前台浏览。

## 整体技术栈建议

| 层级 | 技术选型 |
|------|----------|
| 前端 | Next.js + TypeScript + Tailwind CSS + Framer Motion |
| 后端 | Next.js API Routes / Server Actions |
| 数据库 | Supabase (PostgreSQL) |
| 存储 | Supabase Storage |
| 认证 | Supabase Auth |
| AI 服务 | OpenAI / Claude（多模态 + 文本生成） |
| 部署 | Vercel |

---

## 一、核心功能模块

### 1. 身份验证与访问控制

- 女朋友通过密码 / 特殊日期解锁访问
- 你通过管理员账号登录后台

### 2. 回忆展示端（前台）

- 沉浸式开场
- 时间线故事浏览（按时间 / 章节）
- 多种浏览方式：时间线 / 日历 / 地图 / 分类
- 日记阅读 · 照片精美展示
- 信件 / 生日等特殊页面

### 3. 管理后台（你使用）

- 上传照片（批量）
- 自动识别日期、地点、人物、场景
- AI 生成日记草稿
- 创建 / 调整事件分组
- 选择模板 / 调整排版（可手动润色）
- 发布 / 隐藏 / 编辑回忆

---

## 二、核心流程

1. **上传照片**  
   用户上传照片 → 存入 Supabase Storage

2. **智能识别**  
   读取 EXIF（日期、地点）+ AI 图像识别（场景、人物、情绪）

3. **事件分组**  
   按时间、地点、场景自动聚合成事件（可手动调整）

4. **生成日记**  
   AI 根据照片 + 你的描述 + 关系资料生成日记草稿

5. **智能排版**  
   AI 推荐合适模板 → 自动排版照片 + 文字

6. **预览 & 发布**  
   你预览 → 发布后女朋友可在前台查看

## 三、数据模型（Supabase 表设计建议）

### `users`（管理员）

- `id`, `email`, `password`, `created_at`

### `profile`（关系资料表）

- `id`, `key`, `value`, `created_at`
- 如：第一次见面日期、昵称、爱好等

### `photos`（照片表）

- `id`, `url`, `thumbnail_url`, `taken_at`, `location`, `exif_data`, `ai_tags`, `event_id`, `created_at`

### `events`（事件表）

- `id`, `title`, `description`, `start_date`, `end_date`, `location`, `place_name`, `ai_summary`, `diary_id`, `created_at`

### `diaries`（日记表）

- `id`, `event_id`, `content`, `style`, `created_at`

### `templates`（模板表）

- `id`, `name`, `preview_url`, `config`, `created_at`

### `pages`（页面/章节）

- `id`, `title`, `type`, `event_id`, `template_id`, `content`, `order_index`, `is_published`

### `letters`（信件表）

- `id`, `title`, `content`, `cover_url`, `is_published`, `created_at`

## 四、AI 提示词建议（用于生成日记）

```text
你是一个温柔细致的回忆记录者。请根据以下资料为一段情侣回忆写一篇日记：

- 照片描述：（照片场景、人物、地点、情绪等 AI 识别结果）
- 时间：（拍摄时间）
- 地点：（地点）
- 你的描述：（用户输入的一句话描述，可能为空）
- 我们的关系背景：（昵称、重要纪念日、你们的故事关键词等）

请写一篇真实、自然、有画面感的日记。
风格：（温柔 / 电影旁白 / 幽默等），字数控制在 100–200 字。
```

## 五、自动排版逻辑建议

### 1. 根据照片数量、比例、内容选择模板

| 照片数量 | 推荐模板 |
|----------|----------|
| 单张大图 | 全屏模板 |
| 2–3 张 | 左图右文 / 拼贴模板 |
| 4–9 张 | 网格 / 拼贴模板 |
| 9 张以上 | 胶片风 / 杂志模板 |

### 2. 根据情绪标签选择配色

- 温暖 / 日落色
- 清新 / 绿色
- 电影感 / 胶片风
- 等

## 六、视觉设计参考（请严格参考以下风格与布局）

整体气质：高级、沉浸、电影感；深色背景 + 优雅衬线标题 + 摄影质感。

### 1. 开场登录页（电影感）

- 标题：`PERSONAL MEMORY ARCHIVE`
- 提示：`Identity verification required`
- 输入：陷入日期（MMDD）
- 按钮：`ENTER`

### 2. 首页（不放太多按钮，注重氛围）

- Hero：「我们一起走过的 **867 天**」
- 数据：去过的地方 **18** / 拍下的照片 **1236** / 记录的回忆 **68**

### 3. 时间线浏览页

- 大图纵向滚动
- 日期示例：`05.20`
- 文案示例：「那天的晚风很美，你也很美。」

### 4. 日记详情页（左图右文）

- 左侧两张照片
- 右侧文字栏（日记正文）

### 5. 拼贴模板示例（生活记录）

- 多图叠放 + 便签式文字

### 6. 地图页面（去过的地方）

- 深色地图 + 发光地点钉
- 地点示例：厦门、杭州、成都、重庆（含日期与缩略图）

### 7. 日历页面（每年每一天的回忆）

- 年 / 月网格浏览回忆

### 8. 信件页面（生日信）

- 纸张质感 + 手写风信件

### 9. 响应式设计（手机端示例）

- 首页 / 时间线等在手机上的适配展示

### 10. 排版模板参考（系统内置模板风格）

1. 全屏电影
2. 左图右文
3. 拼贴模板
4. 拍立得叠放
5. 杂志风
6. 日记本风
7. 胶片风

### 11. 管理后台界面（你使用的界面）

- 上传照片区
- AI 生成进度
- 草稿 / 发布设置
